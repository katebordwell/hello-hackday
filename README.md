# Hello, World of Cats

The classic first program, "hello, world", as told by thirty years of internet cats.

**See it live:** https://katebordwell.github.io/hello-world-cats/

From a 1996 ASCII cat to a 2023 cat typing on your laptop mid-meeting. Tap any window to hear its cat say hello.

All the cats are original drawings made in code, so the whole site is a single `index.html` file.
